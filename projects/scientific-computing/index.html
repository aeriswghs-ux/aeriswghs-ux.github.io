Overview

The Python grapher reads environmental channels and creates plots. A separate Flask prototype explores offset correction, summary statistics, and CSV export. These tools support the wind-tunnel project.

Motivation & background

A record is easier to question when its raw values, units, and transformations stay visible. Plotting is part of inspection; it is not proof of sensor accuracy.

Prototype development

Source files for the logger, grapher, and correction tool exist in the linked repository. The current website provides a lightweight viewer for the exact three-row sample fixture.

Results & data

The sample values demonstrate software input. They are not measured wind-tunnel results and cannot support claims about lift, drag, or flow uniformity.

Lessons & future improvements

A corrected number needs a reason. Publish raw datasets, a calibration procedure, units, uncertainties, and source versions with future experiments.

Technical Deep Dive Requirements, methods, validation & limitations

Requirements & constraints

Keep raw and transformed data distinct. Preserve timestamps and units. The Flask prototype requires its own runtime and is linked as source; it does not run on GitHub Pages.

Design concepts & trade-offs

The earlier firmware schedules CSV records every two seconds. That is a configured interval, not a benchmark. A separate correction tool makes offsets inspectable but risks implying accuracy if calibration records are absent.

Calculations & simulations

The earlier modeled pressure channel includes noise and conditioning. Default offsets in the correction prototype are not treated as measured calibration coefficients.

Methodology

For the website viewer, reproduce the existing CSV values exactly, preserve units, and expose a table alongside the chart. No smoothing, extrapolation, or inference is applied.

Problems & failed attempts

No dated software failure log is present in the reviewed record. The available limitation is the absence of independent calibration evidence for default offsets.

Verification & validation

The website checks that chart coordinates and table values reproduce the supplied fixture. This verifies display behavior only; it does not validate the original instruments or research software.

Limitations

Only three sample rows are available. Runtime testing of the original Flask/Python tools and verification of sensor accuracy are outside the evidence currently supplied.
